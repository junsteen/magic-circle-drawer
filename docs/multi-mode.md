# 🎮 マルチモード・コンボモード仕様

## 概要

複数の魔法陣を連続してクリアしていくモード。スコアと残り時間を積み重ねていく。

関連ファイル:
- `src/lib/multiModeConstants.ts` - タイマー・スコア定数
- `src/components/MultiModeGame.tsx` - ゲームロジック
- `src/components/MultiModeReplay.tsx` - リプレイ表示
- `src/components/MultiModeResult.tsx` - 結果表示
- `src/components/ModeSelectScreen.tsx` - モード選択UI

---

## ゲームモード一覧

| モード | 説明 |
|---|---|
| **シングルモード** | 1つの魔法陣を描いてスコアを競う（従来モード） |
| **マルチモード** | 複数の魔法陣を連続クリア、コンボでスコア倍率UP |
| **コンボモード** | マルチモードの上位版（アンロック後に解放） |

---

## タイマー仕様 (`multiModeConstants.ts`)

### 初期時間（秒）

| 難易度 | 初期時間 |
|---|---|
| EASY | 90秒 |
| NORMAL | 60秒 |
| HARD | 45秒 |
| EXPERT | 30秒 |

### ボーナス時間

魔法陣クリア時: **+5秒** 追加

### タイムアップ

残り時間が0になるとゲーム終了。

---

## スコアリング

### コンボ倍率

連続してクリアするごとにコンボカウントが増加し、スコア倍率が上昇。

| コンボ数 | 倍率 |
|---|---|
| 0 | ×1.0 |
| 1 | ×1.2 |
| 2 | ×1.5 |
| 3+ | 最大×3.0まで段階的に上昇 |

### 総合ランク

全魔法陣の平均スコアで最終ランクを決定:

| ランク | 平均スコア閾値 |
|---|---|
| S | 90点以上 |
| A | 70点以上 |
| B | 50点以上 |
| C | 50点未満 |

---

## コンボモード解放条件

**コンボ資格** の取得条件:
- 描画完了時に **残り時間が1秒以上** 残っていること
- ランクが **S または A** であること

コンボ資格を **3回** 取得するとコンボモードがアンロックされる。

---

## データフロー

```
ModeSelectScreen（モード・難易度選択）
  ↓
MultiModeGame（ゲームロジック）
  ├── 各魔法陣の描画 → スコア計算
  ├── タイマー管理（+ボーナス時間）
  ├── コンボカウント更新
  └── drawLogs 収集
  ↓
MultiModeResult（結果表示）
  └── 共有 → ShareModal → KV保存
```

---

## 共有

マルチモードのリプレイデータは `ShareModal` 経由で共有。

- 全魔法陣の描画ログを結合して保存
- Cloudflare KV に保存して8文字IDを発行
- QRコードまたはURLでシェア
- `MultiModeReplay` コンポーネントで再生可能
